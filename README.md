# RC Rumble Arena

Mobil cihazlarda WebView üzerinden, masaüstünde ise tarayıcıda oynanabilen mini araba arena oyunu.

## Oyunu çalıştırma

Flutter uygulaması:

```sh
flutter pub get
flutter run
```

Web sürümünü yerel olarak görmek için `web/index.html` dosyasını bir web sunucusuyla açın. `web/domino.html` doğrudan oyun ekranını içerir.

## Kontroller

- Mobil: Oyun içindeki dokunmatik kontroller
- Masaüstü: WASD veya ok tuşlarıyla sürüş, Space ile özel yetenek

## Web'de yayınlama

GitHub Pages yayını için `web/` klasörü statik site kökü olarak kullanılabilir.
